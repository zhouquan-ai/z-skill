# 简历输出人工审阅清单

- [ ] 输出编号、目标岗位、事实快照日期和版本唯一；
- [ ] 每项经历和项目都能回溯到事实或模块编号；
- [ ] 单位、时间、岗位、资格和数字与事实层一致；
- [ ] 案件客观结果没有写成个人独立创造的成果；
- [ ] “主导”“负责”“代理”“独立完成”等强表述已核对贡献边界；
- [ ] 冲突、单源待核和待证明材料没有被静默删除；
- [ ] 真实单位、客户、案件、薪酬、联系方式和证明材料已完成外发审查；
- [ ] 输出仍标记为待人工审阅，除非使用者确认当前具体版本；
- [ ] 修改事实时已经回到事实层，而不是只改简历文案；
- [ ] 未自动上传、投递或同步到招聘平台。
