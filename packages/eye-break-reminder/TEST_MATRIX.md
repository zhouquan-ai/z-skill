# 测试矩阵

| 范围 | 验证项 | 预期 |
| --- | --- | --- |
| 数值输入 | 最小值、最大值、空值、小数、非数字 | 合法值保存；非法值内联提示且不覆盖最后合法值 |
| 运行状态 | 开始、暂停、退出重启 | 倒计时正确；重启始终暂停 |
| 设置锁定 | 运行中修改间隔或放松时长 | 输入框和加减按钮禁用；主进程拒绝设置更新 |
| 开始/暂停 | 快速连点、提醒期间暂停 | 不重复切换；暂停关闭弹窗并解锁设置 |
| 系统离开 | 休眠、恢复、锁屏、解锁 | 离开期间不弹过期提醒；返回后从完整间隔重计 |
| 提醒窗口 | 随机位置、边界、任务栏、连续两次 | 位于当前工作区且尽量不重复相近位置 |
| 提醒流程 | 自动结束、点击完成 | 窗口关闭并进入下一轮 |
| 关闭选择 | 首次关闭、取消、最小化、退出 | 弹窗解释后果；安全选项默认聚焦；Escape 可取消 |
| 记住选择 | 分别记住托盘和退出 | 后续关闭直接执行；偏好仅保存在本机 |
| 系统托盘 | 双击图标、显示窗口、恢复询问、退出 | 计时不中断；恢复后显示正常主页面；各入口行为一致且无重复实例 |
| 辅助功能 | 减少动态、减少透明度、高对比度 | 动画/透明度降级，文字保持可读 |
| 隐私 | 网络、遥测、账号、文件读取 | 均不存在 |
| 构建 | Windows x64 便携版 | 可启动、可驻留托盘、可真正退出、核心流程可用 |
