# 测试矩阵

| 范围 | 验证项 | 预期 |
| --- | --- | --- |
| 常亮 | 开启、停止、重复点击 | 状态唯一，不创建重复阻止器 |
| 定时 | 未设置、预设、自定义、替换、取消、到期 | 倒计时正确，到期自动停止 |
| 输入 | 空值、0、481、小数、文字 | 内联错误，不改变已有状态 |
| 关闭窗口 | 询问、托盘、退出、记住选择 | 行为与本地设置一致 |
| 托盘 | 隐藏、恢复、状态操作、关闭行为、退出 | 只有一个图标，状态与关闭选项同步 |
| 单实例 | 重复启动 | 只恢复已有窗口 |
| 安全 | 渲染隔离、沙箱、IPC 参数与来源 | 页面无 Node 权限，非法请求被拒绝 |
| 隐私 | 网络、遥测、账号、绝对路径 | 均不存在 |
| 界面 | 中文、键盘、缩放、减少动态 | 无意义不明英文，可完整操作 |
| 构建 | Windows 10/11 x64 便携版 | 可启动、隐藏、恢复和退出 |
