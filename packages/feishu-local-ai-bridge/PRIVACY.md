# 隐私说明

- 公开包不含真实 App ID、App Secret、Token、Cookie、用户 ID、聊天记录、绝对路径或私人工作区。
- 配置模板只引用环境变量名称；不得把真实凭据写回 TOML、Markdown、Git 或回包。
- 消息正文、执行结果和 Git diff 可能含敏感信息，真实系统应设置最小日志字段、保留期限和访问权限。
- 默认只允许私聊、显式允许用户和只读命令；群聊、未知用户和不带前缀的消息应被拒绝。
- 回包只返回必要摘要，不回传完整文件、环境变量、Git 配置、历史消息或原始日志。
- 离线冒烟脚本不联网，只操作使用者明确指定的测试工作区、状态文件和审计文件。
