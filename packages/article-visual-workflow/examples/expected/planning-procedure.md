# 图片计划

## P01

- 决策：示意图
- 对应章节：全过程
- 插入位置：先登记来源、发布日期和访问位置
- 唯一任务：表达登记、分层、冲突保留和回读的顺序
- 决策理由：步骤和回退关系需要准确标签
- 主体与动作：不适用
- 环境与镜头：不适用
- 视觉语言：白底、四个圆角节点、单向主箭头
- 必须出现：来源登记、事实分层、冲突保留、原文回读
- 必须避免：自动判真、自动删除冲突
- ASCII草图：

```text
[来源登记] -> [事实分层] -> [冲突保留] -> [原文回读]
```

- 生成提示：使用确定性绘图工具按ASCII草图绘制四节点流程。
- 验收条件：四个节点逐字准确，阅读顺序从左到右，没有新增自动判断。
- 局部重做条件：只调整文字溢出、节点越界和箭头碰撞。

## P02

- 决策：场景图
- 对应章节：冲突
- 插入位置：保留冲突，不替作者补一个看似合理的数字
- 唯一任务：表现审阅者面对两个冲突数字时选择保留证据
- 决策理由：具体人物动作能够形成阅读节奏，同时不需要准确文字
- 主体与动作：一名成年审阅者把两张无文字数据卡并列保留
- 环境与镜头：干净桌面，俯视近景
- 视觉语言：手绘线稿与少量水彩
- 必须出现：两份并列材料、保留动作、未合并状态
- 必须避免：可读数字、Logo、删除动作、真实报告
- ASCII草图：

```text
[材料A]   [材料B]
      \   /
     [保留夹]
```

- 生成提示：一张独立手绘水彩编辑插画，俯视近景，一名成年审阅者把两份无文字仿真材料并列放入保留夹，不出现数字、Logo、拼贴或删除动作。
- 验收条件：两份材料保持并列且未合并；动作清楚；没有可读数字或Logo。
- 局部重做条件：材料被合并、出现伪文字或画面变成流程图时只重做P02。
