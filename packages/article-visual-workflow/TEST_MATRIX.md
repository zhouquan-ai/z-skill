# 测试记录

> 候选版本：v0.1.0-candidate.1
> 测试日期：2026年7月30日

| 场景 | 当前结果 | 边界 |
|---|---|---|
| Skill 结构与界面元数据 | 发布校验检查 frontmatter、中文名称和安装入口 | 不证明规划质量 |
| 方法型仿真文章 | 形成 1 张场景图、1 张示意图和 1 处不配图决定 | 只覆盖当前仿真结构 |
| 步骤型仿真文章 | 形成 1 张示意图、1 张场景图及局部重做条件 | 只覆盖当前仿真结构 |
| 正文锚点 | `validate_plan.py` 检查每个生成项的插入位置逐字存在于正文 | 不判断语义是否最佳 |
| 路由完整性 | 校验 `场景图`、`示意图`、`不配图` 三种决策及必需字段 | 不调用模型 |
| ASCII 草图 | 示意图计划必须包含最小 ASCII 草图 | 不验证最终像素布局 |
| 提示与验收 | 生成项必须包含提示、验收条件和局部重做条件 | 不代替人工看图 |
| 隐私与路径 | 静态扫描拒绝 Windows 绝对路径、凭据样式和私人工作区名称 | 仍需人工识别间接重识别风险 |
| 确定性 ZIP | 相同源文件两次构建字节一致 | 不证明跨 Agent 行为一致 |

包内测试命令：

```powershell
python -m unittest discover -s packages/article-visual-workflow/tests -v
```

本记录不宣称 Skill 已在所有文章类型、图像模型、Agent 或平台中稳定运行。
