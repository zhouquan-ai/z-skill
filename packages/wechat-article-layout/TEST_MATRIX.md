# 最低测试矩阵

| 场景 | 预期 | 自动化 |
|---|---|---|
| 仿真冻结稿、单图与完整清单 | 生成四项确定性产物 | 已覆盖 |
| 相同输入重复构建 | 输出 SHA-256 一致 | 已覆盖 |
| 图片缺失 | 构建失败并指出文件 | 已覆盖 |
| 清单图片与正文不一致 | 构建失败 | 已覆盖 |
| 未冻结稿 | 构建失败 | 已覆盖 |
| 远程图片或原始 HTML | 构建失败 | 已覆盖 |
| 手机人工验收状态 | 回执保留 `pending/passed/failed`，不自动判定 | 已覆盖 |
| 真实公众号编辑器粘贴、保存重开、手机预览 | 需运行者逐篇执行 | 未自动化 |

运行：

```powershell
python -m unittest discover -s tests -v
```
