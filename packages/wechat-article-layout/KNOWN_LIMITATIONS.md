# 已知限制

- 不调用微信公众号图片、草稿箱、排期或发布 API。
- 自动校验通过只说明输入一致、结构可解析和产物可重建，不代表公众号页面视觉通过。
- Base64 图片便于浏览器内复制，但不等于平台 API 上传，也可能受到编辑器或浏览器策略影响。
- 只支持 README 所列 Markdown 子集；表格、脚注、围栏代码、原始 HTML、复杂嵌套列表会被拒绝或不应投入生产。
- 样式是公开通用基线，不复刻任何私人账号的字号、色值、封面、文末组件或审美参数。
- 微信编辑器、浏览器和移动端渲染会变化；每次实际交付都应重新粘贴、保存重开并手机预览。
- 构建回执不能证明文章已经保存、排期或发布。
