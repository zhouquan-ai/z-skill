# 知识调用流程

## 定义检索目标

先写清当前需要回答的问题、时间范围、主题和证据标准。不要直接用用户整段表达遍历全部资料。

## 选择材料

1. 在调用索引中搜索标题、主题、可用场景和状态；
2. 优先当前有效、来源可靠且与问题直接相关的卡片；
3. 通常选择1至5张，避免用大量低相关材料制造完整感；
4. 卡片只提供定位时，回到原始来源核验。

## 处理时效和冲突

- 当前事实优先于历史口径；
- 官方和原始资料优先于转述；
- 文章观点不直接替代事实；
- 来源冲突时说明冲突、各自依据和当前无法确认的部分；
- 高风险或快速变化问题应重新核验外部当前来源。

## 输出

至少说明：

- 当前结论；
- 使用的知识卡和原始来源；
- 哪些内容是事实、观点或推断；
- 资料的日期和适用边界；
- 冲突、缺口和待验证事项；
- 是否需要更新知识卡。

如果现有材料不足，应明确不足，不用模型常识补成“知识库已有结论”。
