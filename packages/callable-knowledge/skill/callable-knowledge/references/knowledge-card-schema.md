# 知识卡字段

## 必填字段

| 字段 | 说明 |
|---|---|
| ID | 稳定标识，标题变化不自动更换 |
| 标题 | 便于识别的资料名称 |
| 来源 | URL、文件或其他可追溯位置 |
| 作者或机构 | 来源主体；未知时明确写未知 |
| 原始日期 | 资料发布、形成或签署日期 |
| 获取日期 | 实际读取日期 |
| 来源类型 | 官方、原始资料、专业文章、个人经验或其他 |
| 核心内容 | 忠实概括材料实际说明的内容 |
| 可用价值 | 以后可支持什么问题或动作 |
| 适用边界 | 时间、对象、地区、样本或其他限制 |
| 风险与冲突 | 可能过期、争议、缺口或与既有资料冲突 |
| 核验状态 | 已核验、部分核验、待核验或已失效 |
| 后续动作 | 无、补证、复核、转化或其他明确动作 |

## 可选字段

- 主题与关键词；
- 关联知识卡；
- 对应事项或项目；
- 用户判断；
- AI综合判断；
- 替代或被替代关系；
- 最近调用日期和调用场景。

不要把用户判断、AI判断和来源观点混入“核心内容”。同一信息存在多个状态时，保留当前结论并标记旧口径，不让两个互相矛盾的结论并列成为当前事实。
