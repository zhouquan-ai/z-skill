# 知识卡产出与调用

该Workflow把资料保存和知识调用分成两个受控过程：只有明确要求时才建立知识卡；新问题出现时先查索引、选择少量相关卡片，再核对来源、日期和当前有效性。

当前为`v0.1.0-candidate.4`公开候选包，已进入z-skill公开目录。

## 安装

将`skill/callable-knowledge`复制到当前Agent的skills目录。根据自己的目录结构复制或参考`assets/`中的知识卡和调用索引模板。

## 最小验证

1. 提供一篇文章但只要求总结，确认不会自动保存；
2. 明确要求入库，确认同时建立卡片并更新索引；
3. 提出一个新问题，确认只选择少量相关卡片，并对过期事实重新核验。

使用前阅读`PRIVACY.md`、`KNOWN_LIMITATIONS.md`和`TEST_MATRIX.md`。
