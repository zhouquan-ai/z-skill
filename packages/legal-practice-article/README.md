# 法律实务文章写作

这是一个面向律师、法务和企业管理者的法律实务文章写作Skill。它帮助Agent判断文章类型、组织真实材料、核验现行法律与裁判、建立来源对应关系，并在定稿前检查隐私和实操边界。

当前为`v0.1.0-candidate.2`内部候选包，尚未进入z-skill公开目录。

## 安装

将`skill/legal-practice-article`复制到当前Agent的skills目录，重新加载后，用一份已脱敏的法律材料进行测试。

## 最小验证

至少回放两个不同任务：

1. 将流程型内部指引转为公开操作文章，确认不会强行加入无关案例章节；
2. 评论一份真实裁判文书，确认先复现诉辩和法院逻辑，再进行评论。

使用前阅读`PRIVACY.md`、`KNOWN_LIMITATIONS.md`和`TEST_MATRIX.md`。
